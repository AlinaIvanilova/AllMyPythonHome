# Репозиторій для Самостійного Навчання

Цей репозиторій створено мною з метою самостійного навчання та практики.

Тут я зберігаю власні проєкти, вправи, нотатки, приклади коду та інші матеріали, пов’язані з вивченням програмування Python.

---

## Мета

- Поглиблення знань у програмуванні
- Практика з Git та GitHub
- Розвиток навичок розробки програмного забезпечення
- Ведення особистого прогресу в навчанні

---

## Технології

- Python 
- Git та GitHub
- PyCharm

## Статус

Проєкт перебуває в активному розвитку.
